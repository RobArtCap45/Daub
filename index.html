Language & node reference

grid(14, 14) calls a node like a function. Set inputs by position, or by name: grid(cols: 14).

a |> b() sends the value on the left into the next node. let size = 40 gives a value a name you can reuse.

Math is plain: n * 360 + 20 (use + - * / % ^). Comments start with //. End your chain with |> output().

def mine(size = 10) { … } makes your own node. Its parameters become its controls.
